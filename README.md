BazarDor is a modern, responsive Bengali-language market price tracking application. It allows users to explore everyday products, browse products by category, view current prices, compare available market prices, and track daily price changes through a simple and user-friendly interface.

🌐 **Live Link:** [https://bengali-bazar-dor.vercel.app/](https://bengali-bazar-dor.vercel.app/)

---

## 🚀 Technologies Used
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, DaisyUI
- **Backend/Auth:** Better Auth, MongoDB, REST API
- **Tools:** Git & GitHub

---

## ✨ Key Features

1. **Product Library:** Browse everyday products and view their names, categories, units, current prices, and available price-change information.
2. **Product Details:** View detailed product information, including category, unit, average price, minimum and maximum prices, and market-wise prices when available through the API.
3. **Category Browsing:** Explore products by category and navigate easily between different product collections.
4. **Daily Price Tracking:** Identify price increases, decreases, and unchanged prices using clear indicators and Bengali-language price information.
5. **Product Sorting:** Sort products by price from low to high or high to low on category pages.
6. **User Authentication:** Sign up and sign in using the application's Better Auth authentication system.
7. **Profile Management:** View profile information and update supported user details through the profile section.
8. **Responsive Design:** Use the application across mobile phones, tablets, and desktop devices with a responsive interface.
9. **Bengali Language Support:** View localized Bengali text, product information, and Bengali numerals for a more accessible user experience.

## 💻 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/code-craft-nayem/bengali-bazar-dor.git

# Navigate to the project directory
cd bengali-bazar-dor

# Install dependencies
npm install

# Start the development server
npm run dev
